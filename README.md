Intel Arc G3 Extreme vs Ryzen Z2 Extreme: Can Intel Finally Beat AMD in Handhelds?
The Intel Arc G3 Extreme shows a substantial gaming-performance advantage over AMD’s Ryzen Z2 Extreme in some published handheld benchmarks. Intel claims up to 42% higher gaming performance at 35W, while independent testing has reported larger gains in selected games. However, the size of the advantage depends on the game, power profile, device cooling, drivers, and test settings. These results should not be treated as a universal performance difference across all games.

It’s not a rounding error. It’s the kind of generational divide that used to only occur with the release of a new console. On May 28, 2026, Intel debuted the CPU at Computex Taipei. A month later, the MSI Claw 8 EX AI+, the first gadget to use it, was shipped. It was the quickest gaming portable that Notebookcheck has tested.

The price is the true catch. This article explains what the Arc G3 Extreme is, how it compares to the chip that AMD has been selling since 2025, and if it’s worth waiting for one of these devices rather than purchasing what is now available.
